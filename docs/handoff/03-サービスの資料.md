## 1. AIオウンドメディア360

**ひとことで**：キーワードからコンテンツを生み出し、見込み客との接点を増やすサービス。

### 考え方
- 広告費が高くなる中で、積み上がる「資産になる集客」へ移る会社が増えている。オウンドメディア（自社で運用するメディア）はそのための場。
- ただ記事を載せるだけでは成果は出ない。「何のためのメディアか」という戦略、キーワード選び、制作、効果の確かめ、の組み合わせで成果が見えてくる。
- コンテンツ制作は大きく3つ：**キーワード選定 → コンテンツ作成・投稿 → 効果検証**。

### AI と人間のハイブリッド
人が戦略を立て、SEO の専用ツールで構成を最適化し、AI が記事や画像を速くつくる。最後は人が監修して公開する。
- 人（コンサルタント）：ビジネス目標と KPI、ターゲット、キーワードの方針
- SEO ツール：検索上位の記事の見出しや、よく出る言葉をもとに、構成を整える
- AI：記事・画像の下書きを短時間で生成
- 人：監修・修正・公開

→ 人の戦略と AI の制作力を組み合わせ、**品質を保ちつつ、制作のコストを抑える**。

### 「360」＝ 1つのキーワードから広げる
同じキーワードを、いろいろな形に展開して、検索や SNS のあちこちで見つけてもらう。
1. **SEO 記事**（自社サイト）
2. **note**（ドメインの力が強い場所に支店を持ち、自社サイトへ誘導）
3. **映像コンテンツ**（専門家をアニメーションで登場させ、顔出しなしで解説動画に）
4. **SNS コンテンツ**（縦型動画を YouTube・TikTok・Instagram に展開）
5. **オンライン取材記事**（専門家の話を記事に）

進行は、多くの制作物をスプレッドシートで一覧管理する形です。

### 紹介ページの見せ方の案（古屋さんと詰めてください）
- 冒頭：「どんな悩みに効くか」（PV が伸びない／何を書けばいいか分からない／問い合わせにつながらない）
- 中段：360 の広がり（上の5つ）を図に。ここは図があると伝わりやすい
- 終わり：概要まで公開し、詳しい資料は名前・会社・メールアドレスをもらってから渡す

## 3. AIO（AI 検索での見え方）の道具
AI（ChatGPT・Gemini・Claude など）に決めた質問を投げ、回答に自社や競合の名前が出たか、自社サイトが引用されたかを記録して比べる社内ツール（`aio-tracker`、非公開リポジトリ）があります。公開のこの資料には、機能の名前と説明だけを書きます（コードや内部の情報は書きません）。

### 今ある機能（名前と説明）
| 機能 | 説明 |
|---|---|
| サービス登録・競合設定 | 計測する自社サービスと、比べる競合を登録する |
| 質問の生成・管理 | 計測する質問を作って管理する |
| AI 計測 | 決めた質問を AI に公式の仕組みで投げ、回答を記録する |
| 判定・集計 | 名前が出たか・サイトが引用されたかを判定し、指標にまとめる |
| 結果画面 | 言及率・引用率・推薦シェア・勝敗・平均言及順位を画面で比べる |
| 設定 | 計測の設定。ログインは許可された人だけ |

### AIO の道具に予定している機能
大塚の方針：「足りないものは追加する予定。ここに無くて、すでにある機能はそのまま使う」。つまり、**今ある機能は残し、下の表で足りない物を足していく**。紹介ページの機能の説明にも使えます（頻度はどれも月1回）。

| # | 測る項目 | 見る場所・内容 | 今ある機能との関係 |
|---|---|---|---|
| 1 | AI 検索での引用 | ChatGPT・Perplexity・Gemini・Google の AI による概要・Copilot で、決めた質問に自社サイトが引用元に出るか | 引用の判定は「すでにある」。AI の種類（Perplexity・Google の AI による概要・Copilot）は「足す」 |
| 2 | 会社情報の正確さ | 同じ5つの AI で、会社名・所在地・事業内容が正しく答えられるか | 「足す」 |
| 3 | AI 経由の流入 | GA4 の参照元で、chatgpt.com・perplexity.ai・gemini.google.com・copilot.microsoft.com などからのセッション数 | 「足す」 |
| 4 | 検索結果での見え方 | Search Console の「検索パフォーマンス」の検索での見え方で、リッチリザルトの表示回数とクリック率 | 「足す」 |
| 5 | 構造化データの健全性 | Search Console の「拡張」で、更新やページ追加でエラーが増えていないか | 「足す」 |

※「今ある機能との関係」は、公開用に名前と説明だけで整理した表です。実際の実装の状態は、古屋さんが見る権限を得てから `aio-tracker` の README と docs で確かめてください。
