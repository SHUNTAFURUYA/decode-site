# 01 背景と決まった事

## なぜ作り直すか
今の dcd.co.jp（2023年8月版）には、次の悩みがありました。

1. 見た目が古い
2. 今の事業が載っていない（サイトに出ているのは当時の5事業）
3. 問い合わせを増やしたい

## デザインの方向
参考にしたのは **LayerX（https://layerx.co.jp/）のトップの上のほう**です。取り入れたのは次の4つ。

- 最初の画面の見せ方（写真を六角形に切り抜き、青い面を重ねる）
- 白と青の色づかいと余白
- 大きな見出しと短い一文
- スクロールの動き（LayerX の3割くらいに抑える。ふわっと出る・少しずれて動く程度）

**100%まねるわけではありません。** LayerX の長いスクロール演出、1文字ずつ出る見出し、大量の画像が流れる所は入れていません。トーンと動きを借りているだけです。社長の下條さんの OK は取れています。

色はデコデのロゴの青（#0E6EB8、#00A0E9）と白、文字は濃い紺（#152632）。和文は Noto Sans JP、英字の小見出しは Manrope。

## 作りと理由
**Astro の静的書き出し**です。ヘッダー・フッター・事例の詳細ページを1か所で直せて、出力が素の HTML なので、公開先がどこに決まっても置けます（Vercel・Netlify・Cloudflare Pages・普通のサーバー）。ページは `src/pages/`、文章と設定は `src/data/site.ts`、見た目は `src/styles/global.css` です。

## 決まった事
- 見本ではなく、作り直したあとの本番サイトそのものを作る
- ページの範囲は今の dcd.co.jp と同じ（トップ・私たちについて・事業内容・事例とコラム・採用・会社概要・お問い合わせ・プライバシーポリシー）
- 中身は今のサイトの文章を移す（`_ref/` に今のサイトの写しがあります）
- 画像が必要なときは ChatGPT（ブラウザ版）か Codex の画像生成を使ってよい（大塚の了承あり）。実在の人物・会社に見える画像、他社のロゴは作らない
- 公開先・お問い合わせの送り先はまだ決めていない（決めるのは大塚に確認）
