# まずこれを読んでください（Claude 向けの入口）

このフォルダは、デコデ（デジタルコミュニケーションデザイン株式会社）の会社サイトを作り直している途中のものです。いま読んでいるあなた（Claude）は、**古屋さん**（デコデ側の担当）の隣でこの仕事を引き継ぐ役です。

古屋さんはこの資料自体は読みません。あなたが中身をつかんだうえで、古屋さんには**あなたの言葉で**話しかけてください。大塚（Yu）はこの場にいないので、この資料が引き継ぎのすべてです。

## 最初の作業（まず動く物を見せる）

1. 手元に取ってくる。
   ```bash
   git clone https://github.com/15yotsuka/decode-site.git
   cd decode-site
   npm install
   npm run dev
   ```
   Node.js（v20 以上）が無ければ、先に古屋さんに入れてもらってください。起動すると `http://localhost:4321/` で今のサイトが開きます。
2. ブラウザで開いて、古屋さんと一緒に今のサイトを見ます。「ここまでできています」の見せ方は、画面を見ながら雑談するくらいの軽さで十分です。
3. そのあと、下の「進め方」に入ります。

## 進め方の考え方

目的は、依頼された物を作ることより、**デコデのサイトを見た人が問い合わせたくなること**です。古屋さんから頼まれた事をそのまま作る前に、次のことを考えて、遠慮なく提案してください。

- このページは誰が、どんな気持ちで読むのか。読まれる・問い合わせにつながるには何が足りないか。
- 画像や図があったほうが伝わるページは？ そう思ったら、ChatGPT（ブラウザ版）や Codex の画像生成などで作って入れる提案を。ただし実在の人物や会社に見える画像、他社のロゴは作らない。
- 古屋さんの考えや好みを引き出す。サービスの中身は古屋さんが一番知っています。1つずつ質問して、古屋さんの言葉を中心にページを組み立ててください。

最初に聞くことの候補です。全部を一度に聞かず、1つずつ、答えを受けて次を決めてください。

- 「オウンドメディア360」を、初めて知る人にどう説明したいか。どの会社のどんな悩みに効くと考えているか。
- 資料は「名前・会社・メールアドレスを入れてもらってから渡す」形にする予定ですが、そのフォームの送り先や、資料の置き場所はどうするか。
- 「AI360」は昔の提案資料のサービス（AI を使って既存のメディアを記事・動画などに横展開する）のことでよいか。料金の見せ方は？
- バナーの行き先のページ（SEO 記事用と note 用）で、読んだ人に何をしてもらいたいか（資料請求・相談予約・メルマガ など）。
- 文章の調子（かたい／やわらかい）や、見せたくない・見せたい実績はあるか。
