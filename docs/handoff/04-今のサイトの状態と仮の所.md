# 04 今のサイトの状態と仮の所

## できている物
Astro の静的サイトとして、次の11ページがローカルで開けます。

| ページ | パス | ファイル |
|---|---|---|
| トップ | `/` | `src/pages/index.astro` |
| 私たちについて | `/philosophy/` | `src/pages/philosophy.astro` |
| 事業内容 | `/service/` | `src/pages/service.astro` |
| 事例・コラム一覧 | `/case/` | `src/pages/case/index.astro` |
| 事例の詳細（3件） | `/case/<slug>/` | `src/pages/case/[slug].astro` |
| 採用 | `/recruit/` | `src/pages/recruit.astro` |
| 会社概要 | `/company/` | `src/pages/company.astro` |
| お問い合わせ | `/contact/` | `src/pages/contact.astro` |
| プライバシーポリシー | `/privacy/` | `src/pages/privacy.astro` |

- 文章と設定：`src/data/site.ts`（会社情報・事業内容・事例の本文はここ）
- 共通の部品：`src/layouts/Base.astro`、`src/components/`（ヘッダー・フッター・下層ページの上部）
- 見た目：`src/styles/global.css`、動き：`src/scripts/main.js`
- 今の dcd.co.jp の写し：`_ref/`（文章を移すときの元）

確認の済んでいる事：`npm run build` が通る。375・800・1280px の全ページで、横のはみ出しと文字の重なりが0件（Playwright で測定）。

## 仮の所・未確定の所
- **写真**：トップの大きな写真は今のサイトの写真の仮。事例3件の画像は色面の仮。画像が必要なページは、ChatGPT などで生成して差し替える提案を歓迎します（実在の人物・会社・他社ロゴは作らない）。
- **事業内容**：今のサイトの5事業（2023年版）のまま。いまの実態に合わせて直す余地あり。
- **お問い合わせフォーム**：送り先が未定。いまは「送信する」で info@dcd.co.jp 宛のメール作成画面が開くだけで、サーバーには送りません。資料請求の「名前・会社・メール」のフォームの送り先も、同じく**大塚に確かめて決める**。
- **公開先（ドメイン・サーバー）**：未定。決める前に本番に出さない。`src/layouts/Base.astro` に `noindex` が付いているので、公開時に外す（sitemap・GA4・Clarity もそのとき入れる）。
- **プライバシーポリシー**：「8. データのオプトアウト」の提携先リンクが、今のサイトの静的 HTML に出ておらず、文章だけ移してあります。いまの画面に出ているか確認が必要です。
- 実機のスマホ・Safari での見え方は未確認。

## 触り方
```bash
npm install        # 最初に1回
npm run dev        # 確認用（http://localhost:4321/）
npm run build      # dist/ に書き出し（公開前の確認に）
```
新しいページは `src/pages/` に `○○.astro` を足し、先頭で `Base` と `PageHero` を読み込む（`recruit.astro` が一番小さい見本）。ヘッダーのメニューは `src/data/site.ts` の `nav`。
