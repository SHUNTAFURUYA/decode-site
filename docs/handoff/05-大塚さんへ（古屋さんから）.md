## 決めてほしい事（大塚さん）
1. **フォームの送り先**：`src/data/forms.ts` の `endpoint` に入れると、資料申し込み・お問い合わせの両方に反映されます。空のあいだは送信しません（お問い合わせは info@ のメール作成、資料は「準備中」の完了画面）。
2. **資料の渡し方と置き場所**：いまは「メールで送る」。`documentDelivery` を `"download"` にして `downloadUrl` を入れると、送信後にダウンロードできます。
3. **バナーのURL**：公開先のドメインが決まってから確定。バナーの流入元は、フォームの `source`（`banner-seo` / `banner-note`）で区別できます。
4. **公開先とURLの転送**：今のサイトは `/philosophy.html`、`/guide/policy.html`、`/blog/2023-08-14.html` のように `.html` 付き。新しいサイトは `/philosophy/`、`/privacy/`、`/case/<名前>/`。公開時に、古いURLから新しいURLへ転送しないと、検索の評価が途切れます。
5. **BLOGの扱い**：今のメニューには「BLOG」と、タグごとのページがあります。新しいサイトは「事例・コラム」にまとめています。
6. **フォームサービスの引き継ぎ**：今のお問い合わせは、外部のフォームサービス（smoothcontact）の埋め込みです。その送り先の設定を、新しい仕組みへ引き継ぐ必要があります。
7. **ページの説明文（description）**：今のサイトはほとんど空です。公開前に整えてください。
8. 公開時に `noindex` を外し、sitemap・GA4・Clarity を入れる（これまでの引き継ぎのとおり）。
