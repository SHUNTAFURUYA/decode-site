# 02 頼みたい事（古屋さんへのお願い）

大塚の言葉は、次のとおりです。

> 俺に言われたことをただやるだけじゃなくて、どうすればもっと読むようになるだろうっていう思考とかも挟みながらやってほしい。例えば、このページは画像とか欲しいなとかだったら、画像をちゃんと ChatGPT とか何でもいいんだけど、に生成するし、そういう古屋ならではの思考を期待してる。

つまり、作業をこなすだけでなく、**古屋さんならではの発想**で、読まれる・問い合わせにつながるサイトにしたい、という期待です。Claude はこれを踏まえて、古屋さんに提案を返しながら進めてください。

## 4つのお願い

### (1) 引き継ぎ
大塚がやった所までを確かめて引き継ぐ。特に、**今の dcd.co.jp の情報が全部移っているか、最新になっているか**を確かめる。`_ref/` の写しと今の本サイトを見比べ、足りない物・古くなっている物を古屋さんと洗い出す。事業内容の説明は2023年版のままなので、いまの実態に合わせて直す余地があります。

### (2) 「オウンドメディア360」の紹介ページ
サービスの概要までをサイトに載せ、詳しい資料は**名前・会社・メールアドレスを入れてもらってから渡す**形にする。サービスの中身は古屋さんが知っているので、まず古屋さんに聞くのが近道です。考え方の下書きは [03-サービスの資料.md](03-サービスの資料.md) にあります。

### (3) 「AI360」の紹介ページ
大塚が昔提案した資料にある、**AI を使って既存のメディアを記事・動画などいろいろな形に横展開するサービス**。「こういうサービスがあります、こういう料金感です」と見せるページ。分からない所は古屋さんに聞く。料金の数字はこの資料には入れていないので、古屋さんか大塚に確かめる。

関係しそうな物として、AI 検索での見え方を測る道具 `aio-tracker`（https://github.com/dcd-ai-sengoku/aio-tracker、非公開）があります。同じサービスなのか別なのかは、古屋さんに確かめてください。見る権限が無ければ、大塚に頼む。AIO の道具には今後いろいろな機能を足す予定です（[03-サービスの資料.md](03-サービスの資料.md) に予定の機能を書きました）。

### (4) バナーの行き先のページ
デコデのサイトに上げる SEO 記事と、デコデとして出す note の記事に、バナーを入れる予定です。そのバナーを押した先のページを、**SEO 記事用と note 用**に作る。何をしてもらうページにするか（資料請求・相談・無料診断 など）は、古屋さんと決めてください。記事の読者の気持ちが違うので、2つで文言や見せ方を変える案も出してみてください。

## 進め方のヒント
- ページを作る前に、古屋さんに1つずつ質問して、中心に置く言葉を決める。
- 画像や図が効きそうなページは、ChatGPT などで生成して入れる提案をする（実在の人物・会社・他社ロゴは作らない）。
- 作ったら必ずブラウザで開き、スマホ幅（375px）でも崩れていないかを見る。
